# Help

Use Flux's current support routes when documentation and project inspection do not resolve a problem:

- Report reproducible component bugs in the [Livewire Flux issue tracker](https://github.com/livewire/flux/issues).
- Suggest new behavior in [Flux discussions](https://github.com/livewire/flux/discussions).
- Send purchase, billing, and license questions to the contact listed on the [official help page](https://fluxui.dev/docs/help.md).

For an implementation question, include the installed package versions and a minimal Blade/Livewire example so the issue can be reproduced.

**Current source:** [Flux UI help](https://fluxui.dev/docs/help.md).
